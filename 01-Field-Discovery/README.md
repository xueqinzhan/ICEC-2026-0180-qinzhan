## 关于"打不开数据文件"

`.xlsx` 在 GitHub 网页上**只能下载、不能在线预览**（GitHub 不渲染电子表格）。所以每个课题的 `README.md` 里已经把原始数据表**直接内嵌为 Markdown 表格**，在 GitHub 上打开即可阅读、无需下载。

`.xlsx` 原文件一并保留在各自的 `data/` 目录，里面含 Excel 折线图/柱状图，需要本地打开才能看到图。
