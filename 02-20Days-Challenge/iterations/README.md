# 迭代记录

项目四要求「至少 3 次 Git 迭代」。以下 3 次迭代均由**实测中暴露的真实问题**驱动，不是凭空加功能。

每个 `.patch` 文件可用 `git apply` 或任意 diff 工具查看，也可在 GitHub commit 页面直接对比。

---

## 迭代 1：楼层平面图重做

- **Commit**：`dab988b` → `182b6aa`
- **Patch**：`iter1_svg_floorplan.patch`（322 行）

**触发问题**
第一版用 CSS `border: dashed` 画房间框，在手机上几乎看不见——1px 虚线在高分屏上被压缩，且没有任何空间参照物，看不出这是"哪栋楼的哪个位置"。

**改动**
- 删除 CSS 虚线框方案
- 为 3 栋建筑各写一份 SVG 楼层平面图（viewBox 800×500）
- 实绘内容：房间轮廓与填充色、墙体（实线/虚线区分承重与隔断）、窗户（蓝色粗线）、门（棕色虚线弧）、走廊、机柜（数据机房 5 个矩形）、指北针、比例尺（~10m）
- 测量点位叠加在平面图上，坐标由百分比换算为 SVG 坐标

**验收**
手机打开后能辨认出"431 实训室在右上、数据机房在左侧、机房被金属机柜包围"的空间关系。

## 迭代 2：遥测埋点 + 反馈系统 + PWA

- **Commit**：`182b6aa` → `e64a7da`
- **Patch**：`iter2_telemetry_pwa.patch`（2242 行）

**触发问题**
项目四要求「连续 7 天日常运行日志验证」，但 app 完全没有记录能力——无法证明有人在用、用了什么功能、用了多久。同时缺少收集用户反馈的入口。

**改动**
- 新增 `TelemetryLogger` 类：
  - 每次会话生成唯一 `sessionId`，记录 `session_start` / `session_end` 及停留时长
  - 埋点覆盖：标签切换、建筑切换、测量点详情查看、新增点位、删除点位、CSV/JSON 导出、数据重置、筛选操作、热力图渲染
  - 日志存 localStorage，每 30 秒自动保存 + `beforeunload` 兜底
  - `exportLogs()` 按日期导出 JSON
- 新增 `feedback.html` 独立反馈表单（满意度/易用性/准确性三维评分 + 功能需求）
- 新增 PWA：`sw.js` Service Worker 缓存 + `manifest.json`，支持离线打开与桌面安装
- 新增深色模式基础变量、数据管理区（导入/导出/重置）

**验收**
自己用一天后导出，得到 37 条带时间戳与 sessionId 的记录，跨天累积可验证。

## 迭代 3：深色模式 + 信号趋势图 + 一键分享

- **Commit**：`e64a7da` → `86772c0`
- **Patch**：`iter3_darkmode_trend_share.patch`（3986 行）

**触发问题**
1. 同学手机上夜间使用刺眼，且原配色在暗环境下对比度不足
2. 柱状图只能横向比较单点数值，看不出信号随空间位置的衰减走势，而这正是本工具想表达的核心结论
3. 迭代 2 之后需要把 app 推广给同学，但手动复制链接+解释很麻烦，转化率低

**改动**
- **深色模式**：新增 `[data-theme="dark"]` CSS 变量组，Header 加 🌙/☀️ 切换按钮，偏好写入 localStorage 并在启动时恢复；趋势图绘制时读取主题以适配网格与文字颜色；埋点记录 `theme_toggle`
- **信号趋势图**：地图页底部新增 Canvas 折线图 `renderTrendChart()`，按测量顺序绘制信号强度曲线，Y 轴自适应实测极值范围并画 5 级网格线，数据点按信号等级着色（优秀/良好/一般/较差），X 轴标签超 6 字截断
- **一键分享**：数据管理区新增 `shareApp()`，优先调用 Web Share API（移动端原生分享面板），不支持时降级为剪贴板复制，再失败则弹出可手动复制的文本框；埋点记录 `app_shared` 及所用方式

**验收**
深色模式下热力图与趋势图配色正常；Android 端调起系统分享面板成功。
