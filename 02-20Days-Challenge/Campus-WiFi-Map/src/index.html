关于本项目

项目简介

校园WiFi信号地图是一个实用工具，帮助师生快速了解校园各区域的WiFi信号覆盖质量，定位信号盲区。

功能特性

  • 多建筑/楼层切换查看
  • 交互式信号分布地图
  • 添加自定义测量点
  • 信号热力图可视化
  • 数据导出 (CSV/JSON)
  • 离线使用 (PWA)
  • 数据本地存储

数据来源

初始数据来自 2026-10-22 的实地测量，使用 iPhone 15 Pro + Wi-Fi Analyzer 采集 8 个点位共 24 组数据。

技术栈

  • 纯 HTML + CSS + JavaScript
  • SVG 楼层平面图
  • Canvas 热力图渲染
  • localStorage 数据持久化
  • Service Worker 离线缓存
