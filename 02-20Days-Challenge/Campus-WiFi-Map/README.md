# 校园WiFi信号地图

> ICEC 2026 第二阶段开放式项目挑战 | 课题：校园实用软件

## 项目简介

基于校园8个典型点位的24组WiFi信号实测数据，构建交互式信号地图可视化应用。帮助用户直观了解校园各区域的WiFi信号覆盖质量，快速定位信号盲区。

## 数据来源

所有数据均来自 **真实测量**，使用 iPhone 15 Pro + Wi-Fi Analyzer 采集：

- **测试时间**：2026-10-22 14:30-14:40
- **测试点位**：8个（覆盖教学楼、走廊、楼梯、机房、食堂等典型场景）
- **每点位测量**：3轮，共24组数据
- **采集指标**：信号强度(dBm)、延迟(ms)、下载速度(Mbps)、上传速度(Mbps)

原始数据：[data/wifi_signal_raw.csv](data/wifi_signal_raw.csv)

## 功能特性

- **信号分布地图**：8个测试点位在楼层平面图上的空间分布，颜色编码信号质量
- **点击查看详情**：每个点位展示信号强度、延迟、上下行速度及3轮实测明细
- **多维对比图表**：信号强度、下载速度、延迟三项指标的柱状图对比
- **信号等级分类**：
  - 优秀（> -55 dBm）：绿色
  - 良好（-55 ~ -65 dBm）：青色
  - 一般（-65 ~ -75 dBm）：黄色
  - 较差（< -75 dBm）：红色

## 关键发现

| 排名 | 点位 | 信号 | 延迟 | 下载 | 环境特征 |
|------|------|------|------|------|----------|
| 1 | 431实训楼内部 | -44 dBm | 10ms | 82.5 Mbps | 无遮挡/室内 |
| 2 | 走廊靠窗角落 | -50 dBm | 14ms | 59.9 Mbps | 室内/靠窗 |
| 3 | 431走廊靠窗 | -54 dBm | 13ms | 61.6 Mbps | 室内/靠窗 |
| ... | ... | ... | ... | ... | ... |
| 7 | 数据机房 | -82 dBm | 55ms | 14.2 Mbps | 金属机柜遮挡 |

- **信号最强**：431实训楼内部（-44 dBm），靠近AP且无遮挡
- **信号最弱**：数据机房（-82 dBm），金属机柜严重屏蔽
- **衰减规律**：混凝土墙体 > 金属遮挡 > 玻璃 > 开放空间

## 使用方式

直接用浏览器打开 `src/index.html` 即可运行，无需任何依赖。

```bash
# 或使用本地服务器
cd src
python -m http.server 8080
# 访问 http://localhost:8080
```
