# 03 · GitHub 上看不到地图，只看到数据

## 我的提问

> 为什么我在 GitHub 上看不到你这个地图，只看到数据？

## 我的误解

我以为代码推到 GitHub 后，别人打开仓库链接就能看到运行中的地图。

## AI 的解释

GitHub 仓库页面是**代码托管**，不是网站托管：

- `.csv` / `.md` / `.json` → GitHub 会渲染成表格或 Markdown，所以"能看到数据"
- `.html` → GitHub 当作源码展示，只显示转义后的标签文本，**绝不执行 JS**

这是安全设计：如果 GitHub 直接渲染用户上传的 HTML，仓库页面会变成 XSS 和钓鱼页的温床。

## 可选方案对比

| 方案 | 优点 | 缺点 | 结论 |
|-----|------|------|------|
| 本地双击打开 | 零配置 | 只有我自己能看，无法收集 8 人反馈 | ❌ 不满足要求 |
| 截图贴到 README | GitHub 能显示 | 静态图，别人没法交互使用 | ❌ 不算"有人在用" |
| GitHub Pages | 免费、公网 URL、国内可访问 | 需要开 VPN 配置 | ✅ 采用 |
| 国内对象存储托管 | 访问快 | 要账号、要配置 CORS | 未采用 |

## 我的判断

截图方案虽然最快交差，但项目四要求的是"日常运行日志验证 + 真实用户反馈"，静态截图两条都拿不到。**必须真上线。**

这个判断是我做的——AI 给了四个选项，我排除了看起来最省事的截图方案。
