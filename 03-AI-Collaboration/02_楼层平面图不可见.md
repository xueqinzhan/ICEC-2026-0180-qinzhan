# 02 · 楼层平面图不可见

## 我的反馈

> 为什么看不到地图？

## 现象

app 里"信号分布图"这一屏，理论上应该是一张楼层平面图加 8 个测量点标记。实际打开后是一片近乎空白的区域，只能看到几个小圆点，完全看不出空间关系。

## 原因

第一版实现用 CSS 画房间：

```css
.room {
    border: 1px dashed #999;
    /* 靠 div 定位模拟房间 */
}
```

三个问题叠加：

1. **1px 虚线在高分屏手机上被压缩**，几乎不显示
2. **没有房间名称、墙体、门窗**，即使看见框也不知道是什么
3. **没有比例尺和朝向**，无法建立"这是哪栋楼"的空间认知

## AI 的方案

放弃 CSS 画框，为每栋建筑写一份 SVG 平面图，`viewBox="0 0 800 500"`。

实绘内容：
- 房间轮廓 + 填充色区分功能（实训室蓝、走廊黄、机房紫、门口粉）
- 墙体：实线表示承重墙，`stroke-dasharray="5,3"` 表示隔断
- 窗户：`#4FC3F7` 蓝色粗线（4px）
- 门：`#8B6914` 棕色虚线
- 数据机房内 5 个机柜矩形（解释为什么这里信号最差）
- 右下角指北针 + 左下角 ~10m 比例尺
- 背景网格 pattern 辅助定位

测量点位仍用百分比坐标，渲染时换算：`left: x%` / `top: y%` 叠加在 SVG 上。

## 验收

手机打开后能说出"431 实训室在右上、数据机房在左侧、机房里全是金属机柜所以信号差"。

**这次改动的价值不在于代码变好看了，而在于让 -82dBm 这个数字有了可解释的空间原因。**
